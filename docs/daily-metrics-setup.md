# 日次のヘルスケア数値をシートに足す（ショートカット + Apps Script）

HealthFit が書き込んでくれるのはワークアウト単位の記録だけです。
安静時心拍数・HRV・体重などの「毎日の状態」は、iPhone のショートカットから
同じスプレッドシートの `Daily` タブに投げます。追加費用はかかりません。

所要時間は 20〜30分。指標を5つに絞った最小構成から始めます。

| 指標 | ヘルスケアでの名前 | 単位 |
| --- | --- | --- |
| 安静時心拍数 | 安静時心拍数 | bpm |
| HRV | 心拍変動 | ms |
| VO2max | 心肺機能 | mL/kg/min |
| 体重 | 体重 | kg |
| 歩数 | 歩数 | 歩 |

睡眠は取り出し方が少し面倒なので、動くようになってから足すのがおすすめです（最後に補足あり）。

---

## Step 1. 受け口を作る（Apps Script・10分）

1. Running タブがあるスプレッドシートを開く
2. **拡張機能 → Apps Script**（このシートに紐づいたスクリプトになります）
3. `コード.gs` の中身を全部消して、`apps-script/daily-metrics.gs` の内容を貼る
4. `TOKEN` の値を自分で決めた長いランダム文字列に書き換える
   （例: パスワードマネージャで32文字生成。**あとでショートカット側にも同じものを入れます**）
5. 保存（⌘S）
6. 右上の **デプロイ → 新しいデプロイ**
   - 種類: **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
7. 初回は権限の確認が出ます。「詳細」→「（安全ではないページ）に移動」→ 許可
8. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピー

> 「アクセスできるユーザー: 全員」は、URL を知っている人がリクエストを送れる状態です。
> だから `TOKEN` が必要になります。URL とトークンは他人に渡さないでください。

**確認:** その URL をブラウザで開いて `{"ok":true,...}` が返れば成功です。

---

## Step 2. ショートカットを作る（15分）

ショートカットアプリ → 新規作成。名前は「朝のヘルスケア送信」など。
アクションは全部で 13 個です。

> **ループでまとめられないか？**
> できません。「ヘルスサンプルを検索」のタイプ指定は選択式で、変数を差し込めないためです。
> 指標のリストを「各項目を繰り返す」で回しても、中の検索アクションの型は固定のままになります。
> そのぶん、**1ペア作ってから複製する**のが最短です（下記）。

### 2-1. 5つの数値を取り出す

指標ごとに **2つのアクション** をペアで置きます。まず安静時心拍数から:

1. 「**ヘルスサンプルを検索**」を追加
   - タイプ: **安静時心拍数**
   - 並び替え: **開始日** / **降順**
   - 制限: **1**（「制限」がなければ「上限」のトグルをオン）
2. 「**変数を設定**」を追加
   - 変数名: `rhr`
   - 値: 直前の結果をタップ → プロパティから **値** を選ぶ（ここが重要。サンプルそのものではなく数値を入れる）

残り4つは、**このペアを長押し → 複製** して作ります。並び替えと制限の設定を引き継ぐので、
変えるのはタイプのドロップダウンと変数名だけです。

| タイプ | 変数名 | 検索の設定 |
| --- | --- | --- |
| 心拍変動 | `hrv` | 降順・制限1 |
| 心肺機能 | `vo2max` | 降順・制限1 |
| 体重 | `weight` | 降順・制限1 |
| 歩数 | `steps` | 期間を **今日** にして制限なし（次で合計します） |

歩数だけは1日に何件も記録されるので、「ヘルスサンプルを検索（歩数・今日）」のあとに
「**統計を計算**」を挟みます。演算は **合計**、入力は見つかったサンプルの **値**。
その結果を「変数を設定」で `steps` に入れてください。

### 2-2. 送る中身を1枚のテキストで作る

「**テキスト**」アクションを追加して、次を丸ごと貼り付けます。

```
{"token":"ここにトークン","resting_hr":"[rhr]","hrv":"[hrv]","vo2max":"[vo2max]","weight":"[weight]","steps":"[steps]"}
```

貼り付けたあと `[rhr]` などの位置をタップして、対応する変数に差し替えてください。

**値は必ず引用符で囲みます。** Watch を着けずに寝た日は変数が空になりますが、`""` なら
JSON として壊れず、スクリプト側が空欄として扱います。囲まないと `"hrv":,` になって
その日の送信ごと失敗します。

日付は送りません。`date` を省略すると、スクリプトがシートのタイムゾーンで「今日」を入れます。

> 辞書アクションを使っても構いませんが、キーを1行ずつ手入力することになります。
> テキスト1枚のほうが速く、あとから指標を足すときも1か所の編集で済みます。

### 2-3. 送る

3. 「**URL の内容を取得**」を追加
   - URL: Step 1 でコピーしたウェブアプリの URL
   - 「詳細を表示」を開く
   - 方法: **POST**
   - 本文を要求: **ファイル**
   - 本文に、直前の **テキスト** を指定
4. （デバッグ用）「**通知を表示**」を追加して、直前の結果を表示させる

辞書を使った場合は、本文を要求を **JSON** にして辞書を指定してください。

### 2-4. 手動で1回実行する

再生ボタンで実行します。初回はヘルスケアへのアクセス許可を聞かれるので許可してください。
通知に `{"ok":true,"date":"2026/07/27","updated":false}` が出て、
シートに `Daily` タブと1行できていれば完成です。

---

## Step 3. 毎朝自動で走らせる

1. ショートカットアプリ下部の **オートメーション** タブ → 右上の **+**
2. **時刻** を選ぶ → **毎日** → 起床後の時間（例 7:30）
   - 安静時心拍数と HRV は睡眠中の値から計算されるので、起きて少し経ってからが確実です
3. 「**すぐに実行**」を選ぶ（これを選ばないと毎朝確認通知が出ます）
4. 実行するショートカットに「朝のヘルスケア送信」を指定

数日動かして安定したら、Step 2-4 の「通知を表示」を削除すると静かになります。

## うまくいかないとき

| 症状 | 原因と対処 |
| --- | --- |
| `{"ok":false,"error":"トークンが一致しません"}` | テキスト（辞書）の `token` とスクリプトの `TOKEN` が違う。前後の空白にも注意 |
| `{"ok":false,"error":"SyntaxError..."}` | テキストの JSON が壊れている。値を引用符で囲み忘れていないか（空の指標があると起きる） |
| HTML が返ってくる | デプロイ設定が「自分のみ」になっている。「全員」で再デプロイ |
| 一部の値が空欄 | その日のサンプルがない。安静時心拍数・HRV は Watch を着けて寝た日だけ記録されます |
| 何も起きない | Apps Script の左メニュー「実行数」でリクエストが届いているか確認 |
| コードを直したのに反映されない | **デプロイ → デプロイを管理 → 鉛筆 → バージョン: 新バージョン** で再デプロイが必要 |

## あとから足せるもの

- **睡眠時間**: タイプ **睡眠** で「昨日18:00〜今日12:00」を検索し、「各項目を繰り返す」で
  各サンプルの `期間` を足す。合計秒を 3600 で割って `sleep_hours` として送る
- **体脂肪率・安静時消費エネルギー**: 同じ形でペアを増やし、テキストにキーを1つ足すだけ。
  `daily-metrics.gs` の `COLUMNS` 末尾に追加すれば列も増えます
- **ラップ・GPS ルート**: HealthFit にすでにある FIT/GPX 書き出し（iCloud か Dropbox 宛の自動化）を使うのが早いです

## ダッシュボードへの取り込み

`Daily` タブができたあと、`lib/sheet.ts` と同じ流儀で `Daily` を読む関数を足せば、
「安静時心拍数が上がっている週」と「距離を増やした週」を並べて見られるようになります。
現状のアプリはまだ Running タブだけを読んでいます。
