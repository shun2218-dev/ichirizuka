# 日次のヘルスケア数値をシートに足す（ショートカット + Apps Script）

HealthFit が書き込んでくれるのはワークアウト単位の記録だけです。
安静時心拍数・HRV・体重などの「毎日の状態」は、iPhone のショートカットから
同じスプレッドシートの `Daily` タブに投げます。追加費用はかかりません。

所要時間は 20〜30分。指標を5つに絞った最小構成から始めます。

| 指標 | ヘルスケアでの名前 | 単位 |
| --- | --- | --- |
| 安静時心拍数 | 安静時心拍数 | bpm |
| HRV | 心拍変動 | ms |
| VO2max | 心肺機能 | mL/kg/min |
| 体重 | 体重 | kg |
| 歩数 | 歩数 | 歩 |

睡眠は取り出し方が少し面倒なので、動くようになってから足すのがおすすめです（最後に補足あり）。

---

## Step 1. 受け口を作る（Apps Script・10分）

1. Running タブがあるスプレッドシートを開く
2. **拡張機能 → Apps Script**（このシートに紐づいたスクリプトになります）
3. `コード.gs` の中身を全部消して、`apps-script/daily-metrics.gs` の内容を貼る
4. `TOKEN` の値を自分で決めた長いランダム文字列に書き換える
   （例: パスワードマネージャで32文字生成。**あとでショートカット側にも同じものを入れます**）
5. 保存（⌘S）
6. 右上の **デプロイ → 新しいデプロイ**
   - 種類: **ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
7. 初回は権限の確認が出ます。「詳細」→「（安全ではないページ）に移動」→ 許可
8. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピー

> 「アクセスできるユーザー: 全員」は、URL を知っている人がリクエストを送れる状態です。
> だから `TOKEN` が必要になります。URL とトークンは他人に渡さないでください。

**確認:** その URL をブラウザで開いて `{"ok":true,...}` が返れば成功です。

---

## Step 2. ショートカットを作る（15分）

ショートカットアプリ → 新規作成。名前は「Ichirizuka 日次記録」など。
アクションは 13 個（動作確認用の「通知を表示」を入れて 14 個）です。

> **ループでまとめられないか？**
> できません。「ヘルスケアサンプルを検索」のタイプ指定は選択式で、変数を差し込めないためです。
> 指標のリストを「各項目を繰り返す」で回しても、中の検索アクションの型は固定のままになります。
> そのぶん、**1ペア作ってから複製する**のが最短です（下記）。

### 2-1. 5つの数値を取り出す

指標ごとに **2つのアクション** をペアで置きます。まず安静時心拍数から:

1. 「**ヘルスケアサンプルを検索**」を追加して、次のように設定する

   | 項目 | 値 |
   | --- | --- |
   | 種類 が次と等しい | **Resting Heart Rate**（安静時心拍数）。既定は `Steps` なのでタップして変える |
   | 開始日 が次の過去の期間内 | **1 日**（既定は 7 日。古い値を今日の行に書かないため） |
   | 単位 | 拍/分。既定のままでよい |
   | グループ分け | なし |
   | 並び順序 | **開始日** を選び、**新しい順**にする |
   | 制限 | **オン** にして **1**（トグルを入れると数を入れる欄が出る） |

2. 「**変数を設定**」を追加
   - 変数名: `rhr`
   - 値: 直前の結果をタップ → プロパティから **値** を選ぶ（ここが重要。サンプルそのものではなく数値を入れる）

アクション名は検索欄に「ヘルスケア」と入れると出てきます（「ヘルスケアサンプルを**記録**」は
書き込み用なので間違えないこと）。プロパティに「値」が出ない場合は、代わりに
「**ヘルスケアサンプルの詳細を取得**」を挟んで **値** を取り出しても同じです。

残り4つは、**このペアを長押し → 複製** して作ります。変えるのは次の 3 か所だけです。

| 種類（英語表記） | 変数名 | 単位 | 開始日 |
| --- | --- | --- | --- |
| Heart Rate Variability（心拍変動） | `hrv` | ms | 過去の期間内 1 日 |
| VO2 Max（心肺機能） | `vo2max` | mL/(kg·min) | 過去の期間内 1 日 |
| Weight / Body Mass（体重） | `weight` | **kg**（lb になっていたら必ず変える） | 過去の期間内 1 日 |
| Steps（歩数） | `steps` | 歩 | **今日**（下記） |

**期間を 1 日にする理由。** 広げると「3日前に測った体重」を今日の行に書いてしまい、
測っていない日を測ったように見せることになります。空欄のままにしておけば、ダッシュボード側は
欠測として扱い、平均も「7日中N日の平均」と明記します。VO2max のように数日おきにしか
更新されない指標も、空欄が続くのが正しい状態です。

歩数だけは扱いが違います。1日に何件も記録されるので合計が必要です。

- 開始日フィルタを **「が今日」** にする（無ければ「過去の期間内 1 日」でも可）
- 並び順序は **なし**、制限は **オフ**（全件必要なため）
- 直後に「**統計を計算**」を挟む。演算は **合計**、入力は見つかったサンプルの **値**
- その結果を「変数を設定」で `steps` に入れる

### 2-2. 送る中身を1枚のテキストで作る

「**テキスト**」アクションを追加して、次を丸ごと貼り付けます。

```
{"token":"ここにトークン","resting_hr":"[rhr]","hrv":"[hrv]","vo2max":"[vo2max]","weight":"[weight]","steps":"[steps]"}
```

貼り付けたあと `[rhr]` などの位置をタップして、対応する変数に差し替えてください。

**値は必ず引用符で囲みます。** Watch を着けずに寝た日は変数が空になりますが、`""` なら
JSON として壊れず、スクリプト側が空欄として扱います。囲まないと `"hrv":,` になって
その日の送信ごと失敗します。

日付は送りません。`date` を省略すると、スクリプトがシートのタイムゾーンで「今日」を入れます。

> 辞書アクションを使っても構いませんが、キーを1行ずつ手入力することになります。
> テキスト1枚のほうが速く、あとから指標を足すときも1か所の編集で済みます。

### 2-3. 送る

3. 「**URL の内容を取得**」を追加
   - URL: Step 1 でコピーしたウェブアプリの URL
   - 「詳細を表示」を開く
   - 方法: **POST**
   - 本文を要求: **ファイル**
   - 本文に、直前の **テキスト** を指定
4. （デバッグ用）「**通知を表示**」を追加して、直前の結果を表示させる

辞書を使った場合は、本文を要求を **JSON** にして辞書を指定してください。

### 2-4. 手動で1回実行する

再生ボタンで実行します。初回はヘルスケアへのアクセス許可を聞かれるので許可してください。
通知に `{"ok":true,"date":"2026/07/27","updated":false}` が出て、
シートに `Daily` タブと1行できていれば完成です。

---

## Step 3. 毎日自動で走らせる

1. ショートカットアプリ下部の **オートメーション** タブ → 右上の **+**
2. **時刻** を選ぶ → **毎日** → **22:00 前後**
3. 「**すぐに実行**」を選ぶ（これを選ばないと毎日確認通知が出ます）
4. 実行するショートカットを指定

**朝ではなく夜に走らせます。** 朝だとその日の歩数がまだ数百歩しかなく、
毎日ほぼ 0 の値がシートに残ってしまうためです。夜なら 1 日分の指標が出そろっています。

- 安静時心拍数と HRV は睡眠中の値から計算され、日中には当日の値が入っています
- 体重と VO2max は測った時点で入ります

朝に走らせたい場合は、歩数だけ別のオートメーション（夜）に分ける必要があります。

数日動かして安定したら、Step 2-3 の「通知を表示」を削除すると静かになります。

---

## Step 4. 過去の分を取り込む（任意・1回だけ）

毎日の送信は「その日の 1 行」を作るだけなので、始める前の記録は入りません。
ヘルスケアには過去のサンプルが残っているので、**1 指標ずつまとめて流し込む**専用の
ショートカットを作って 5 回実行します。

新規ショートカット「Ichirizuka 過去分の取り込み」を作り、次の 4 アクションを並べます。

1. 「**ヘルスケアサンプルを検索**」
   - 種類: **Resting Heart Rate**
   - 開始日 が次の過去の期間内: **7 日**（まず短くして試す。うまくいったら 180 日に広げる）
   - **グループ分け: 日** ← 1 日 1 件にまとめる。歩数はこれで 1 日の合計になる
   - 並び順序: **開始日**
   - 制限: **オフ**
2. 「**各項目を繰り返す**」を追加し、その中に「**テキスト**」を 1 つ置く

   ```
   [開始日],[値]
   ```

   `[開始日]` は繰り返し項目の**開始日**プロパティ。タップして
   **日付フォーマット → カスタム → `yyyy/MM/dd`** にする。`[値]` は**値**プロパティ
3. 繰り返しの外に「**テキストを結合**」を追加
   - 入力: 繰り返しの結果
   - 区切り: **カスタム** → **`;`**（JSON の文字列に改行は入れられないため）
4. 「**テキスト**」→「**URL の内容を取得**」（POST / 本文を要求: ファイル）

   ```
   {"token":"ここにトークン","metric":"resting_hr","rows":"[結合結果]"}
   ```

実行して `{"ok":true,"metric":"resting_hr","added":6,"updated":1,"skipped":0}` のような
応答が返り、シートに過去の日付の行が増えていれば成功です。

うまくいったら **`metric` と種類だけ変えて 5 回**実行します。

| 種類 | `metric` に入れる値 |
| --- | --- |
| Resting Heart Rate | `resting_hr` |
| Heart Rate Variability | `hrv` |
| VO2 Max | `vo2max` |
| Weight / Body Mass | `weight` |
| Steps | `steps` |

- 同じ日の行があれば**その列だけ**上書きします。毎日の送信で入れた値は消えません
- 値が空の日と読めない行は飛ばします（`skipped` に数が出ます）
- 「グループ分け: 日」が効かない場合、歩数以外はグループ分けなしでも実用上問題ありません
  （同じ日のサンプルが複数あると、最後の 1 件で上書きされます）。歩数だけは件数が多すぎるので、
  グループ分けが使えないなら諦めるのが早いです
- 全部終わったらこのショートカットは消して構いません

## うまくいかないとき

| 症状 | 原因と対処 |
| --- | --- |
| `{"ok":false,"error":"トークンが一致しません"}` | テキスト（辞書）の `token` とスクリプトの `TOKEN` が違う。前後の空白にも注意 |
| `{"ok":false,"error":"SyntaxError..."}` | テキストの JSON が壊れている。値を引用符で囲み忘れていないか（空の指標があると起きる）。過去分の取り込みなら、区切りが改行のままになっていないか |
| `{"ok":false,"error":"date が読めません: undefined"}` | スクリプトが古い。`today()` が無ければ貼り直して**新バージョンで再デプロイ** |
| 過去分で `skipped` ばかり増える | テキストの日付にフォーマット（`yyyy/MM/dd`）を指定していない。または値プロパティではなくサンプルそのものを入れている |
| HTML が返ってくる | デプロイ設定が「自分のみ」になっている。「全員」で再デプロイ |
| 一部の値が空欄 | その日のサンプルがない。安静時心拍数・HRV は Watch を着けて寝た日だけ記録されます |
| 何も起きない | Apps Script の左メニュー「実行数」でリクエストが届いているか確認 |
| コードを直したのに反映されない | **デプロイ → デプロイを管理 → 鉛筆 → バージョン: 新バージョン** で再デプロイが必要 |

## あとから足せるもの

- **睡眠時間**: タイプ **睡眠** で「昨日18:00〜今日12:00」を検索し、「各項目を繰り返す」で
  各サンプルの `期間` を足す。合計秒を 3600 で割って `sleep_hours` として送る
- **体脂肪率・安静時消費エネルギー**: 同じ形でペアを増やし、テキストにキーを1つ足すだけ。
  `daily-metrics.gs` の `COLUMNS` 末尾に追加すれば列も増えます
- **ラップ・GPS ルート**: HealthFit にすでにある FIT/GPX 書き出し（iCloud か Dropbox 宛の自動化）を使うのが早いです

## ダッシュボードへの取り込み

`Daily` タブができたあと、`lib/sheet.ts` と同じ流儀で `Daily` を読む関数を足せば、
「安静時心拍数が上がっている週」と「距離を増やした週」を並べて見られるようになります。
現状のアプリはまだ Running タブだけを読んでいます。
