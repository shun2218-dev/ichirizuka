# デザイン

紙の記録帳・方眼紙を思わせる落ち着いた印刷物の見た目。数値を主役にし、装飾は罫線と余白で作る。

## 原則

- **数値が主役。** 見出しやラベルは小さく抑え、数字を大きく置く
- **面ではなく線で区切る。** 影やグラデーションでカードを浮かせない。1px の罫線と余白で構造を作る
- **色は意味を持つときだけ使う。** 装飾目的で色を足さない。カラースケールは心拍（負荷）を表すためだけに存在する
- **依存を持たない。** グラフはすべて手書きの SVG。チャートライブラリもアイコンフォントも使わない

## カラー

すべて `app/globals.css` の `:root` に定義する。生の色値をセレクタ内に直接書かない。

### 面と線

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--paper` | `#e8eced` | ページ背景。紙の色 |
| `--card` | `#f6f8f8` | プロット領域・テーブル帯の背景 |
| `--grid` | `#d6dee0` | 方眼の線、グラフの目盛り |
| `--rule` | `#c2ced2` | セクション区切り、枠線 |

### 文字

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--ink` | `#14202b` | 本文・数値 |
| `--muted` | `#64757f` | 補足、ラベル、テーブルヘッダー |
| `--faint` | `#94a4ac` | 単位、最も弱い注記 |

### アクセント

| 変数 | 値 | 用途 |
| --- | --- | --- |
| `--teal` | `#1f7a78` | リンク、フォーカスリング、進捗バー、増加方向 |
| `--amber` | `#e0a73b` | カラースケール中間 |
| `--magenta` | `#c9436b` | カラースケール上端、減少方向 |

### 心拍のカラースケール

`lib/format.ts` の `effort()` / `effortColor()` が担当する。

- 145bpm を 0、180bpm を 1 に正規化（範囲外はクランプ）
- 心拍が `null` の場合は 0.35 として扱う
- 0 → 0.5 → 1 を teal → amber → magenta で線形補間

この 3 色以外をスケールに足さない。凡例は必ず「145bpm → 180bpm」と併記する。

## タイポグラフィ

| 変数 | フォント | 用途 |
| --- | --- | --- |
| `--display` | Barlow Condensed (600/700) | 見出し、ワードマーク、大きな数値 |
| `--body` | Noto Sans JP (400/500) | 本文 |
| `--mono` | Roboto Mono (400/500) | **すべての数値**、ラベル（eyebrow） |

Google Fonts から `app/layout.tsx` で読み込む。`preconnect` 済み。

**数値は必ず等幅（`--mono`）にする。** テーブルの数値セルには `className="mono"` を付ける。桁が揃わないと比較できないため。

本文は 15px / line-height 1.6。

### eyebrow

セクションの上に置く小さなラベル。`--mono` 11px、`letter-spacing: 0.16em`、`text-transform: uppercase`、色は `--muted`。

## レイアウト

- コンテンツ幅は最大 1060px、中央寄せ、左右 20px のパディング（`.shell`）
- セクション間の余白は `--gap`（28px、780px 以下では 22px）
- セクションは上罫線（`--rule` 1px）で区切る

### ブレークポイント

**780px の 1 つだけ。** 780px 以下でヒーローと負荷セクションを 1 カラムに落とし、`--gap` を 22px に縮める。それ以外は同じレイアウトで通す。

細かいブレークポイントを増やさない。

### 方眼

プロット領域（`.plot`）は `linear-gradient` を 2 枚重ねて方眼を描く。背景は `--card`、線は `--grid`。

## グラフ

すべて自前の SVG。`viewBox` で座標系を固定し、幅は親要素に追従させる。

### 共通ルール

- `role="img"` と `aria-label` を必ず付ける
- 目盛り線は `--grid`、軸ラベルは `--mono` の小さい文字で `--muted`
- 目盛りの刻みはデータのピークに応じて間引く（`YearStrip` は 10 / 20 / 30km 刻みを切り替え）

### YearStrip（52 週ストリップ）

- 棒の幅 9px、間隔 4px、左マージン 30px、プロット高 128px、軸高 26px
- 縦軸の上限は `max(週目標 × 1.2, 実測の最大値)`
- 棒の色は週平均心拍を `effortColor()` に通した値
- 週目標を破線で重ねる

### PaceScatter（距離 × ペース）

- 縦軸がペース（**上にあるほど速い**＝値が小さい）
- 直近 180 日のランのみ

### IntensityStrip（週ごとの強度の配分）

- 棒の幅 14px、間隔 6px。26 週なので `YearStrip` より太くできる
- **積み上げ棒。下から easy → moderate → hard。**高さはその週の合計時間
- 色は心拍スケールの 3 点（`--teal` / `--amber` / `--magenta`）を**そのまま**使う。
  スケールが元々「低い強度 → 高い強度」を表しているので意味が一致する。新しい色は足さない
- 記録のない週は `YearStrip` と同じ細い線で表す

**達成度メーターにしない。** 実測では easy が 1 割程度で、ゲージ形式にすると常に「未達」を
指すだけになり情報量がない。割合は数値と 1 本の帯で示し、変化は週ごとの推移で見せる。

### ConditionChart（安静時心拍数 × 走行距離）

- **上下 2 段に分ける。**単位が違うものを 1 つの縦軸に重ねると読み間違えるため、軸を共有しない
  - 上段: 週平均の安静時心拍数（折れ線、`--ink`）。目盛りは下限・中間・上限の 3 本
  - 下段: その週の走行距離（棒、`--teal` を `fill-opacity: 0.6`）
- x 軸は共有。ラベルは月初を含む週にだけ月の数字を出す（`YearStrip` と同じ）
- **欠測週で線を繋がない。**測っていない週を測ったように見せないため、連続した区間ごとに `polyline` を分ける
- 心拍のカラースケールは使わない。ここでの色は「距離の棒」と「心拍の線」を区別するためだけのもの

## インタラクション

- トランジションは控えめに。`prefers-reduced-motion: reduce` ですべて無効化する
- フォーカスリングは `--teal` 2px、`outline-offset: 2px`。**消さない**
- ホバーで情報が増えるだけの表現は避け、必要な情報は常時表示するかテーブルに置く

## 動的な値

バーの幅や心拍による色のように、値が実行時に決まるものだけインラインスタイルで書く。それ以外はすべてクラスと CSS 変数で表現する。

```tsx
<div className="target-fill" style={{ width: `${weekPct}%` }} />
<span className="chip" style={{ background: effortColor(effort(r.hr)) }} />
```

## ダークモード

**未対応。** `themeColor` は `--paper` と同じ `#e8eced` 固定。対応する場合は `:root` の変数を `prefers-color-scheme` で切り替える形にする（各セレクタに手を入れずに済むよう、色は必ず変数経由で参照しておくこと）。
